# 🌱 Organic Farm Store – E-Commerce Platform

## ✅ Project Overview
**Organic Farm Store** is a modern, full-stack e-commerce web application designed for buying and selling organic farm products.  
Built using **React** for the frontend, **Django** for the backend, and deployed on **AWS**, this platform enables a responsive user experience for customers while offering powerful admin capabilities and intelligent product recommendations using machine learning.

## 🎯 Key Features

### 🌾 Farm Product Store
- Responsive and user-friendly product browsing interface.
- Detailed product pages with images, descriptions, and prices.
- Filter products by category, price, and availability.

### 👥 Role-Based Access
- **Customer Role:** Browse products, add to cart, place orders, view order history.
- **Admin Role:** Add, update, delete products, manage orders, view analytics.

### 🛒 Product Cart
- Add/remove products to a cart.
- Cart persists across sessions (with user login).
- Place orders and manage payment (mocked).

### 🤖 Machine Learning Product Recommendations
- Smart product recommendation system based on user behavior and purchase history.
- Suggest similar or complementary products in real-time.

### ⚡ SEO Optimized
- Meta tags, descriptions, and optimized URL structure for better Google search ranking.

## 🖥️ Software and Hardware Requirements

### Software:
- Frontend: React JS, HTML, CSS, JavaScript  
- Backend: Django, Django REST Framework  
- Database: PostgreSQL / MySQL  
- Machine Learning: scikit-learn / TensorFlow / PyTorch  
- Deployment: AWS EC2, S3, Route53  
- IDE: VS Code, Postman

### Hardware:
- Minimum 4 GB RAM, 64-bit OS  
- Modern Browser (Chrome / Firefox)  
- Optional GPU (for training ML models faster)
